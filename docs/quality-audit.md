# گزارش بررسی و اصلاح فایل‌منیجر

تاریخ: 2026-10-24

کد رابط، مسیرهای سرور، عملیات فایل، مدیریت حساب و تنظیمات بررسی شد. اصلاحات در همین پروژه اعمال شده‌اند. فایل‌ها و پایگاه‌دادهٔ اصلی کاربر برای آزمایش استفاده نشدند؛ آزمایش مرورگر با پوشه و پایگاه‌دادهٔ جداگانه در فضای موقت انجام شد. تغییر قبلی کاربر در `renovate.json` حفظ شد.

## نتیجهٔ آزمون‌ها

- کل تست‌های Go با `go test -race ./...` موفق بودند؛ تشخیص رقابت داده فعال بود.
- ۱۱ تست جدید رابط API و مسیرها با `npm test` موفق بودند.
- بررسی TypeScript با `npm run typecheck` موفق بود.
- بررسی Go با `golangci-lint run` صفر ایراد گزارش کرد.
- `npm run build` و ساخت فایل اجرایی Go موفق بودند.
- تست‌های رابط API به گردش کار CI اضافه شدند؛ ساخت رابط نیز اکنون TypeScript را بررسی می‌کند.

ساخت رابط دو هشدار غیربازدارنده دارد: قدیمی بودن دادهٔ آماری مرورگرها و بزرگ بودن بستهٔ JavaScript. این‌ها خطای ساخت یا شکست عملکرد نیستند.

## خروجی و استفاده

فایل اجرایی `filebrowser` در ریشهٔ پروژه دوباره ساخته شده است. نسخهٔ اجرایی قبلی در `filebrowser.before-audit.bak` نگه داشته شد. برای استفاده از اصلاحات، نمونهٔ قبلی برنامه را ببندید و همان روش اجرای معمول خود را دوباره اجرا کنید. پایگاه‌دادهٔ اصلی تغییر داده نشد.

## محدودیت بررسی

این گزارش تضمین «صفر خطا در همهٔ شرایط» نیست. Redis خارجی، CAPTCHA تنظیم‌شده روی سرویس واقعی، ورود پشت پراکسی واقعی، HTTPS و تنظیمات Nginx/Docker محیط نهایی، همهٔ کدک‌های رسانه‌ای، قطع برق واقعی، دیسک پر و بار هم‌زمان سنگین در محیط واقعی اجرا نشده‌اند. تست زیرآدرس و شاخه‌های کد با آزمایش اتصال به سرویس خارجی یکسان نیست. رابط همچنان انگلیسی است؛ گزینهٔ زبان در پروفایل قالب تاریخ را تغییر می‌دهد. قابلیت سطل زباله/بازگردانی حذف در این تغییر اضافه نشده است.
